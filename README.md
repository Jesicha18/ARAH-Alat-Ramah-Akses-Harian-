## 📌 Tentang Project
**ARAH (Alat Ramah Akses Harian)** adalah inovasi *Smart Cane* (tongkat pintar) berbasis Internet of Things (IoT) yang dirancang untuk membantu mobilitas penyandang tunanetra. Project ini menggabungkan perangkat keras mikrokontroler dengan sistem monitoring berbasis web *real-time* menggunakan Laravel.

---

## ✨ Fitur Utama
- **Deteksi Hambatan Otomatis:** Sensor terintegrasi untuk mendeteksi rintangan di sekitar pengguna secara *real-time*.
- **Dashboard Monitoring:** Memantau status dan data perangkat secara langsung melalui web aplikasi berbasis Laravel.
- **Sistem Peringatan Dini:** Memberikan respons cepat demi meningkatkan keselamatan mobilitas pengguna.

---

## 🛠️ Teknologi yang Digunakan
- **Hardware / IoT:** ESP32 / Arduino, Sensor Pendukung, Mikrokontroler.
- **Backend & Web Dashboard:** Laravel Framework (PHP), MySQL.
- **Frontend:** Blade, Tailwind CSS / Styling pendukung.
